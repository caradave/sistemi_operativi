# Sistemi Operativi – Laboratori e Esercizi

Questa repository raccoglie gli esercizi e i laboratori svolti durante il corso di **Sistemi Operativi** al Politecnico di Torino.

## 🧠 Obiettivi del corso

Il corso fornisce le basi teoriche e pratiche per comprendere il funzionamento dei sistemi operativi moderni, focalizzandosi su:

- Gestione dei processi
- Creazione e sincronizzazione di thread
- Comunicazione tra processi (IPC)
- Utilizzo di chiamate di sistema POSIX
- Gestione della memoria e file system
- Utilizzo del terminale Linux

## 📁 Contenuto

- `lab1/`, `lab2/`, ... – Soluzioni dei laboratori settimanali
- `README.md` – Questo file

> ⚠️ I testi degli esercizi originali non sono inclusi per rispetto delle policy dell’ateneo.

## 🔧 Compilazione ed esecuzione

Tutti i file sono scritti in C standard POSIX e testati su Linux.  
Per compilare:

```bash
gcc -o programma programma.c -lpthread
./programma
```
